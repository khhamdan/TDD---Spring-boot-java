Test-Driven Development (TDD) is a software development approach that emphasizes writing tests before writing the actual code. 
In TDD, we first create a failing test that defines the desired behavior, then implement the minimal code required to make the test pass. 
Once the test passes, the code is refactored for clarity and efficiency. This cycle is summarized as Red → Green → Refactor → repeated for every small functionality, ensuring that the code is correct, maintainable, and reliable from the start.
